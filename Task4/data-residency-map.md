# Data Residency Map: Africa Delivery

- **Last Updated:** 2026-08-28 (время кейса)
- **Primary Infrastructure Providers:** AWS af-south-1 (Кейптаун) + AWS Local Zone Лагос; вторая площадка в Нигерии — MTN Cloud (Лагос); DR — GCP africa-south1 (Йоханнесбург)
- **Compliance Jurisdictions:** Нигерия — NDPA 2023 / GAID 2025 (ранее NDPR); Кения — Data Protection Act 2019 + Regulations 2021, KICA; ЮАР — POPIA
- **Основа:** шаблон курса Data_Residency_Map. **Исправлено:** в шаблоне финансовые данные Нигерии хранятся во Франкфурте — ровно сценарий «звонок министра» (A1, A7). Кроме того, шифрование с CMK в шаблоне подаётся как замена локализации. **Шифрование не снимает требование хранить данные в стране:** зашифрованная копия за рубежом — всё равно трансграничная передача.

## 4. Регламент трансграничной передачи

1. По умолчанию данные остаются в стране субъекта. Страна определяется при регистрации (код номера +234 / +254 / +27). Приложение обращается к endpoint ячейки своей страны (`api-ng` → ALB в Лагосе): **запросы с ПДн нигерийцев не проходят через Кейптаун** — ни TLS-терминация, ни WAF-логи, ни воркеры партнёров.
2. Передача разрешена, только если она есть в разделе 3. Новая передача = запись в реестре обработок + оценка (TIA) + согласование DPO + обновление этой карты.
3. Механизмы: KE → ZA — стандартные договорные положения ODPC; ZA → наружу — ст. 72 POPIA; NG → наружу — **не используем** до заключения юристов (Q-06).
4. Контроль: ежедневный DLP-скан логов и выгрузок на номера +234 и NIN; алерт = инцидент SEV2. Уведомление регулятора об утечке — по срокам страны (KE: 72 ч ODPC).

## 5. Технические меры безопасности и соответствия (Security & Technical Compliance Overrides)

- **Изоляция:** ячейка NG — отдельный namespace, отдельная БД и отдельные ключи. Сетевая политика пропускает из ядра в ячейку только API токенизации и заказов.
- **Ключи:** полевое шифрование ПДн NG — ключами ячейки (OpenBao в Лагосе). Диски — шифрование EBS. Право на удаление — crypto-shredding: ключ покупателя уничтожается, и данные в бэкапах становятся нечитаемыми.
- **Сроки хранения (допущение до Q-06):** финансовые записи — 7 лет; KYC — 5 лет после окончания отношений; согласия — пока действуют, + 3 года как доказательство; логи — 90 дней; адреса у перевозчика — 30 дней.
- **Аудит:** журнал доступа к ПДн хранится в стране субъекта в режиме WORM (только запись). Для ядра — S3 Object Lock в af-south-1; для Нигерии поддержку WORM в хранилище MTN Cloud нужно проверить (в Local Zone Лагос S3 нет), запасной вариант — неизменяемая таблица с хеш-цепочкой в PostgreSQL ячейки.

## Assumptions

- **AS-07** (Task1) — консервативно: все данные нигерийцев — в Нигерии.
- **AS-30.** Физическое хранение в Лагосе у американского провайдера удовлетворяет «данные в стране» (Q-01). Если нет — ячейка переезжает к MTN Cloud ([ADR-003](adr-003-data-residency.md), раздел «Обратимость»).
- **AS-31.** Сроки хранения — по самому длинному из вероятных требований (налоговый учёт, AML) до ответа юристов.
