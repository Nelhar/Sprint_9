# Architecture Canvas — Africa Delivery

**Дата (время кейса):** 2026-08-14. **Решающий голос:** инвестор; бюджет делегирован CFO, технологии — CTO и архитектору ([stakeholder-matrix.md](stakeholder-matrix.md)).

| Цели (измеримые) | Ключевые драйверы | Ограничения (жёсткие) |
|---|---|---|
| **15.10.2026** — пилот NG + KE: 5 000 SKU от 100 продавцов, оплата M-Pesa и Flutterwave, SMS и мессенджеры, кабинет покупателя, аналитика для CEO (У) | **Срок, а не масштаб**: реклама на $180k оплачена (A2) | 15.10, страницы в сторах к 01.10 (A1, A2, A7) |
| **Успех 16.10:** «люди покупают, продавцы получают деньги, ничего не ломается, министр не звонит» (A1) | **Стоимость эксплуатации**: дожить до 7-го месяца (A6) | ≤ $5k/мес; > $500 — с согласия CFO; без предоплат; оплата по счёту за 45 дней (A6 п.1–4) |
| **12 мес.:** 5 стран, > 1 млн пользователей, B2B, кабинет продавца, track & trace, возвраты, 3+ языка (У) | **Резидентность данных** по странам (A3, A7) | 6 контракторов, найм заморожен (A6 п.5) |
| **3 года:** 12–15 стран, 40% рынка (A1, A7) | **3G/4G с обрывами**, телефоны < $150 (У, A2) | Без лицензий; платежи ≤ 2,5% GMV с FX (A6 п.6–7) |
| | **Партнёры** — главный источник отказов (У); **доверие** (A2) | Платежи — только через лицензированного партнёра (A3 п.4); NDPA, POPIA, KDPA, KICA |

| Риски (топ) | Принципы |
|---|---|
| **R1.** Сторы к 01.10: D-U-N-S до 7 раб. дней, ревью 2–7 дней | **Вовремя важнее идеала**: walking skeleton к неделе 4 |
| **R2.** Облако по счёту — через реселлера, закупка ≈ 3 недели (A6 п.4) | **Partner-first**: сами строим только тонкие адаптеры |
| **R3.** Юристы (05–19.09) потребуют больше заложенного (A3) | **Обратимость**: ячейки данных по странам |
| **R4.** Отказ партнёров (Sendy в администрировании с 2023), PSP в пике | **Managed по умолчанию** (CN.MSV.01) |
| **R5.** Наплыв ×10–50 после рекламы; **R6.** кассовый разрыв (C-08); **R7.** нет людей с локального рынка (У) | **Late binding** по триггерам; **трассировка** решений к C-xx |

## Assumptions

| ID | Допущение | Подтверждает |
|---|---|---|
| AS-05 | Пилот — **Лагос и Найроби**, остальное — 48 ч через партнёров; ЮАР — после пилота (У, A2) | CEO (Q-04) |
| AS-06 | Старт — до 100 тыс. MAU, пик ×10; «1 млн за месяц» — маркетинговая цель, не план мощности (C-02) | CEO, CFO |
| AS-07 | ПДн нигерийцев, включая псевдонимизированные заказы, хранятся и обрабатываются **в Нигерии** (A3 п.1, A7; C-05) | Инвестор (Q-01), юрист |
| AS-08 | $12k/мин — пиковая минута распродажи, а не каждая минута года | Инвестор (Q-02) |
| AS-09 | Лимит $5k — инфраструктура и SaaS; SMS, WhatsApp, USSD и комиссии PSP — транзакционные, вне лимита (A6 п.1) | CFO (Q-03) |
| AS-10 | «On-prem как вариант» (A5) — готовность к переезду, а не on-prem в день 1 | CTO (Q-05) |
| AS-11 | Go остаётся языком разработки — компетенция CTO (A5) | CTO |
