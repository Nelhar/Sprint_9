Масштаб покупается по триггерам, а не заранее.

## Обозначения источников

**A1** — транскрипт встречи с инвестором · **A2** — маркетинговый бриф · **A3** — письмо юриста · **A4** — 29 функций PM · **A5** — письмо CTO (+ вложение «чек-лист CN») · **A6** — письмо CFO · **A7** — записка инвестора · **A8** — схема системы · **У** — описание проекта · **Ш-TCO / Ш-FMEA / Ш-DRM** — шаблоны курса. Ссылка вида «A6 п.1» означает пункт 1 письма CFO. Номера: допущения **AS-xx** (разделы `## Assumptions`), противоречия **C-xx**, пробелы во входных данных **G-xx**, вопросы **Q-xx**.
