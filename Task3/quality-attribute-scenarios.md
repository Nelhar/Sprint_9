# Quality Attribute Scenarios

**Дата (время кейса):** 2026-08-25. **Шаблон** — [приложение В](../templates/qas-template.md), шесть полей SEI. Каждый сценарий проверяется до 01.10: нагрузочный тест, учения по отказам, RUM.

## QAS-01. Доступность: отказ зоны во время флеш-распродажи

| Поле | Значение |
|---|---|
| Атрибут / НФТ | Доступность — NFR-01, NFR-09 |
| 1. Источник стимула | Инфраструктура AWS af-south-1 |
| 2. Стимул | Отказ одной зоны доступности (AZ-a): теряется primary RDS и треть узлов K8s |
| 3. Среда | Пик флеш-распродажи недели запуска, 50 заказов/с |
| 4. Артефакт | Оформление заказа: монолит + RDS PostgreSQL Multi-AZ |
| 5. Отклик | RDS переключается на standby в AZ-b; поды перезапускаются в живых зонах; приложение повторяет идемпотентные запросы |
| 6. Мера отклика | Недоступность ≤ 2 мин; **0 потерянных** оплаченных заказов (RPO = 0); ≤ 0,5% запросов с ошибкой за окно; бюджет ошибок 28 дней сгорает не больше чем на 5% |

## QAS-03. Пропускная способность: всплеск после live-стрима

| Поле | Значение |
|---|---|
| Атрибут / НФТ | Масштабируемость — NFR-07, NFR-08 |
| 1. Источник стимула | 50 000 зрителей live-стрима блогера (A2 обещание 7, 17.10) |
| 2. Стимул | ×20 к средней нагрузке за 5 минут: переходы по ссылке в стриме на 3 товара |
| 3. Среда | Обычная работа, кеш прогрет за 30 мин до эфира (runbook маркетинга) |
| 4. Артефакт | Каталог, корзина, резервирование остатка флеш-распродажи |
| 5. Отклик | CDN поглощает чтение. HPA добавляет поды, Cluster Autoscaler — узлы. При насыщении включается **очередь ожидания** вместо 5xx. Остаток резервируется атомарно в PostgreSQL |
| 6. Мера отклика | ≥ **1 000 RPS** на origin и **50 заказов/с**; масштабирование ≤ 15 мин; ошибки ≤ 1%; **0 продаж сверх остатка** (overselling). Очередь ожидания не прячет нехватку мощности: **≥ 90%** прошли очередь ≤ 2 мин, ушедших из очереди < 5% (метрики `waiting_room_seconds`, `waiting_room_abandoned_total`) |

## QAS-04. RTO/RPO: потеря региона af-south-1

| Поле | Значение |
|---|---|
| Атрибут / НФТ | Восстанавливаемость — NFR-10 |
| 1. Источник стимула | Провайдер (региональный сбой) или блокировка аккаунта |
| 2. Стимул | Регион Кейптаун недоступен больше 30 минут |
| 3. Среда | Г1: pilot light в GCP africa-south1 — малый Cloud SQL как непрерывная логическая реплика RDS (Google DMS, pglogical), ежедневный `pg_dump` в GCS, образы, Terraform. Г2: warm standby |
| 4. Артефакт | Ядро: каталог, остатки и их резерв **для всех стран, включая Нигерию**; заказы Кении (с 6-го мес. — и ЮАР); CDN-origin |
| 5. Отклик | Дежурный объявляет DR (решение — CTO, [Task4/failover-plan.md](../Task4/failover-plan.md)). Реплику Cloud SQL повышают до primary и увеличивают инстанс; Terraform поднимает GKE; DNS и origin CDN переключаются. Каталог всё это время отдаётся из CDN (`stale-if-error` 24 ч) |
| 6. Мера отклика | Г1: **RTO ≤ 4 ч, RPO ≤ 15 мин** (фактически — лаг репликации, алерт > 5 мин). Г2: **RTO ≤ 30 мин, RPO ≤ 5 мин**. **Нигерия не автономна:** ПДн и уже созданные заказы остаются в ячейке и дооплачиваются, но **новые заказы в Нигерии тоже недоступны** до переключения ядра — резерв остатка живёт в ядре. RTO для Нигерии тот же |

## QAS-05. Устойчивость к отказу партнёра: M-Pesa не отвечает

| Поле | Значение |
|---|---|
| Атрибут / НФТ | Отказоустойчивость интеграций — NFR-18, NFR-19 |
| 1. Источник стимула | Внешний PSP (Safaricom Daraja) |
| 2. Стимул | Тайм-ауты STK Push > 30% за 1 минуту |
| 3. Среда | Обычная нагрузка в Кении |
| 4. Артефакт | Адаптер `payments/mpesa` |
| 5. Отклик | Circuit Breaker размыкается **для новых заказов**: им предлагается оплата через Flutterwave (M-Pesa через агрегатора) или «оплатить позже по SMS-ссылке». Заказы, по которым STK уже отправлен и истёк тайм-аут, переходят в `PAYMENT_UNKNOWN`: покупатель мог подтвердить оплату на телефоне. По ним — STK Push Query; другой PSP предлагается только после ответа «не оплачено» или истечения срока STK-запроса. Пулы соединений других адаптеров не затронуты (Bulkhead) |
| 6. Мера отклика | Обнаружение ≤ 1 мин; SLI-PAY-1 (доступность API) держится, а **просадка SLI-PAY-6** (время до подтверждения оплаты) видна на дашборде, а заказы «оплатить позже» в статусе `AWAITING_CUSTOMER_PAYMENT` идут отдельной строкой и не будят дежурного по SLI-PAY-7 — деградация не маскируется под успех. **0 неразобранных** двойных списаний за сутки; двойные возвращены ≤ 24 ч; пробное замыкание каждые 30 с |

## QAS-06. Резидентность: запись ПДн гражданина Нигерии

| Поле | Значение |
|---|---|
| Атрибут / НФТ | Соответствие требованиям — NFR-16 |
| 1. Источник стимула | Покупатель с номером +234 регистрируется |
| 2. Стимул | Запись профиля, адреса и телефона |
| 3. Среда | Обычная работа; юристы ещё не дали заключение (A3) |
| 4. Артефакт | Точка входа ячейки NG (ALB + ingress в Local Zone Лагос, домен `api-ng`) + PII-хранилище ячейки |
| 5. Отклик | Приложение по стране регистрации обращается сразу в Лагос, TLS терминируется в Нигерии, ядро в Кейптауне запрос с ПДн не видит. В ядро и логи уходит только токен `cust_ng_…`; логи маскируются на источнике |
| 6. Мера отклика | **0** записей ПДн NG вне Нигерии по ежедневному DLP-скану. Задержка регистрации p99 < 1 с |

## Assumptions

- **AS-49.** Профиль сети для QAS-02 — 3G с потерей пакетов 2% и RTT 150–300 мс; объём до первого товара ≤ 150 КБ (миниатюра WebP + JSON карточки).
- **AS-50.** Пик 50 заказов/с и 1 000 RPS на origin — из AS-25 (5% MAU одновременно, ×3 на флеш-распродаже) с запасом ×10 к прогнозу.
