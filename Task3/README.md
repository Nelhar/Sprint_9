**Ключевое решение.** 99,9% на критическом пути в Г1 окупается в 11 раз ($34k против $395k сэкономленных потерь). 99,95% (+$162k/год) окупается с Г2, 99,99% (+$405k/год) — от $1,9k средней минуты, то есть с Г3–4. До тех пор идём по лестнице SLO. Не путать с точкой безубыточности всего варианта CTO ($18,0k/мин, Task2).
